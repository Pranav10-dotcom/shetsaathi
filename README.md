# 🌾 शेतसाथी (ShetSaathi)
### Marathwada Farmer's Companion — Offline-First Decision System

> *"शेतसाथी is an offline-first, region-specific farmer intelligence system designed for Marathwada, providing crop recommendation, cost estimation, and real-time decision support based on irrigation, weather, and market conditions."*

---

## 📱 Live Demo
Open `index.html` in any browser — no internet required for core features.

## 🎯 Product Vision
ShetSaathi helps Marathwada farmers:
- Decide **what to grow** based on their land, irrigation & budget
- Understand **cost & profit** with realistic range estimates
- Follow **step-by-step farming guides** in Marathi
- Track **weather + market prices** for smarter selling
- **Reduce risk** in drought-prone conditions

---

## 🧩 MVP Modules

| Module | Description |
|--------|-------------|
| 🌱 Smart Crop Selection | Recommends crops based on irrigation, season & budget |
| 💰 Cost & Profit Engine | Shows min–max cost/yield/profit per crop per acre |
| 🪜 Farming Guide | Step-by-step Marathi instructions for each crop |
| 🌦️ Weather Intelligence | Forecast + farm-specific alerts |
| 📈 Market Intelligence | APMC prices, MSP alerts, buy/sell advice |
| 📶 Offline-First | All core logic works without internet |

---

## 🌾 Supported Crops

**Kharif:** Soybean · Cotton · Tur (Pigeon Pea) · Groundnut  
**Rabi:** Wheat · Gram (Chickpea) · Onion · Garlic  
**Advanced:** Onion Seed 🌱

---

## 🧠 Decision Logic (Rule-Based)

```
IF no irrigation      → suggest Tur, Gram
IF drip + high budget → suggest Onion, Garlic  
IF moderate rainfall  → suggest Soybean, Groundnut
IF risky conditions   → avoid Cotton (beginners)
```

## 🎨 Design Principles
- 🗣️ **Marathi-first** UI
- 📍 **Marathwada-specific** (not generic India)
- 💧 **Water-aware** decision system
- ⚠️ **Risk-based** intelligence (safe crops for beginners)
- 📶 **Offline-first** architecture

---

## 🏗️ Tech Stack
- Pure **HTML + CSS + JavaScript** — no frameworks, no dependencies
- Works in any browser, on any device
- Offline capable via stored crop/guide data
- Responsive mobile-first layout (420px optimized)
